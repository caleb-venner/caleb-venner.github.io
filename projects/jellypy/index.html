JellyPy: keeping Sonarr and Radarr in step with Jellyfin

A Jellyfin plugin that keeps Sonarr and Radarr aligned with what's actually being watched, with push notifications and event-driven scripts.

Caleb Venner · v2.1.0.0 · GPLv3 · Code on GitHub

Jellyfin serves a media library, while Sonarr and Radarr manage what gets downloaded into it. On their own, they don't know what anyone is actually watching, so keeping them in step means a steady stream of repetitive library admin.

JellyPy is a Jellyfin plugin, written in C# on .NET against the Jellyfin plugin API, that closes the gap. The aim is to cut that admin down while keeping the plugin's behaviour transparent and configurable.

How it works

Media sync

As you watch, JellyPy automatically monitors upcoming episodes in Sonarr and unmonitors watched media in Radarr. That keeps the download queues focused on what you're actually watching.

Notifications

JellyPy has native ntfy.sh integration for push notifications, with grouped updates and media image previews. That makes it easy to see what the automation is doing without opening a dashboard.

Scripts and security

JellyPy can run Python, Bash or binary scripts when Jellyfin events fire, which makes it a general hook for other automation. The script execution guide covers how that works.

API keys for Sonarr and Radarr are stored with server-bound AES-256 encryption, and built-in connection testing lets each connection be checked during setup.
